# ChatBot Furia

Um chatbot interativo desenvolvido para fornecer informações sobre a FURIA Esports. Construído com HTML, CSS e JavaScript, utilizando a plataforma Typebot.io.

## 🚀 Funcionalidades

- Interface intuitiva e responsiva
- Respostas automáticas sobre a FURIA
- Informações sobre times e jogadores
- Integração com Typebot.io
- Design moderno e interativo

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Typebot.io

## 📦 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/fq38/chatbot-furia.git
```

2. Navegue até o diretório do projeto:
```bash
cd chatbot-furia
```

3. Abra o arquivo `index.html` em seu navegador ou use um servidor local.

## 💻 Como Usar

1. Acesse a página do chatbot
2. Digite sua pergunta na caixa de diálogo - exemplo 
" me conte a historia da fuira e-sport "
3. O chatbot responderá com informações relevantes sobre a FURIA
